# 4.0.2 — ALPHA publiée sur PyPI le 2026-10-10

Date de publication opérateur : 2026-10-10, après qualification T05 et GO de
Romain. Aucun rang leaderboard revendiqué.

- Doctor d'installation, registre de neuf clients, setup créant exclusivement un
  jeton absent en mode 0600 ; aucun secret écrit dans les configurations.
  Diagnostic de configuration distinct d'un handshake réel. `doctor --store-only`
  conserve les compteurs JSONL/SQLite sans réseau ; `--json` fournit les checks.
- HTTP authentifié /health et /ready, Host/Origin contrôlés, relais sans rejeu
  automatique après résultat incertain, comportement 4.0.1 conservé.
- Déduplication par identité/texte normalisé ; une similitude vectorielle seule
  ne fusionne ni ne remplace un fait distinct. Outil de réparation ciblée par
  plan versionné, simulation par défaut ; aucun incident production réparé ici.
- C4 **défaut proposé** : corpus BM25 scoped_literal, garde de trois places puis
  fusion. Rollback env legacy/0. Décision et effets de compatibilité :
  [RELEASE_4_0_2_DECISIONS](../../v4/docs/RELEASE_4_0_2_DECISIONS.md).
- LongMemEval-S : 500 cas sans erreur ; recall sur 479 cas avec preuve,
  466 clusters : .754 [.721;.785] vs BM25 .712, Δ+.042 [.022;.061] ;
  MRR .626 vs .614, Δ+.012 [.008;.0164]. MiniLM, extraction sans LLM,
  annotations réservées au scoreur. Questions déjà observées via oracle,
  distracteurs fixes, pas indépendant, pas une exactitude de réponse officielle.
  p50 bout en bout 19,7 s/question (ingestion d'environ 50 sessions), pas 19,7 s
  par recherche chaude. Granite/multilingue et qualité de réponse à qualifier.
- SQLite S2 transactions moteur/cache/rétention et S3 migration hors ligne source
  inchangée inclus **opt-in uniquement**. Index reconstruisibles et tests de panne
  légers. Backup/restauration industrielle SQLite S4 non livrés : backup ops refuse
  cette base ; JSONL par défaut reste non atomique entre fichiers.

Python ≥3.11, LGPL-3.0-or-later ; moteurs v3/v4 et cinq commandes installées :
`memory-os-ai`, `memory-os-v4`, `memory-os-ai-v3`, `memory-os-relay`, `memory-os-admin`.
Le dossier `releases/4.0.2/QUALIFICATION.md` décrit les contrôles exécutés et ceux
qui ont précédé la publication. L'activation et la migration d'un magasin local
restent des opérations distinctes de l'installation du paquet.
