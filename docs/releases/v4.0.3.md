# 4.0.3 — candidate ALPHA, non publiée et non déployée

Le GO du 2026-10-10 autorise la construction et la qualification **sur copie**.
Il n'autorise ni publication, ni modification du service/magasin de production.

C4 reste le défaut approuvé. `device=auto`, précision `native`, batch 32 et
max_seq_length 512 préservent les réglages du serveur 4.0.2 sur le Mac : **MPS**,
avec dtype réel à observer. Aucun passage implicite à CPU/float32/batch4.
SQLite S2/S3 demeure opt-in ; S4 backup/restore industriel reste à qualifier.

`memory_status` et `/ready` authentifié exposent `encoding_profile` : device
résolu, politique de précision, dtypes/devices réellement chargés, batch/max_seq,
révision modèle connue, versions Torch/ST/Transformers/NumPy, empreinte du code
encodeur, normalisation et dtype de sortie. Le dtype numpy float32 n'atteste pas
celui du calcul. Une révision absente est annoncée, jamais inventée ; elle crée
un namespace privé non réutilisable entre instances. Les métadonnées de révision
ne sont pas une signature des poids ; les protocoles de mesure hachent aussi
les fichiers du snapshot. Aucune identité bit à bit entre kernels promise.

Les caches JSONL historiques sans profil complet sont reconstruits **une fois**
avant la première requête. SQLite ne réutilise que les embeddings dont l'empreinte
corpus/profil concorde. Un redémarrage à profil inchangé ne réencode pas le corpus
(un warmup et l'encodage des requêtes demeurent possibles). Un changement de
runtime/backend/précision ne mélange jamais de nouveaux vecteurs aux anciens.
Ce premier rebuild est un changement d'exploitation qui exige mesure sur copie.

Preuves retrieval historiques : LME-S observé réussit son critère ; BEAM observé
échoue au sien. L'essai MPS float32/batch4 ne prouve pas l'équivalence CPU à ±1 pt.
Ces essais diffèrent du profil natif/batch32 déployé. **Aucun rang leaderboard ni
score officiel d'exactitude revendiqué.** Le pilote de réponses autorisé reste
exploratoire : [protocole](../../v4/bench/protocols/answer-pilot-production-v1.md).

Les cinq commandes, LGPL-3.0-or-later et Python ≥3.11 sont conservés.
