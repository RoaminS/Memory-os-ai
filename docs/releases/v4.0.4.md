# 4.0.4 — candidate ALPHA, 2026-10-11

Non publiée, non déployée. Les autorisations PyPI et bascule sont distinctes.

- Maintenance destructrice désactivée côté serveur par défaut ; les souvenirs
  restent des données, jamais des instructions ou une autorisation.
- Relais durable : journal local fsync, adoption en lecture seule des journaux
  orphelins, statut local pendant panne, empreintes raw/canonical côté serveur,
  aucun rejeu automatique d'une mutation incertaine. JSONL ne promet pas une
  transaction atomique multifichier ; SQLite reste opt-in.
- Rotation du jeton relue après reconnexion ; identité amont changée signalée
  explicitement ; catalogue d'outils conservé pendant panne. Version MCP relayée.
- `/ready` et doctor décrivent les capacités effectivement déployées et leurs
  limites ; les observations clients récentes ne sont pas une preuve de présence.
- Brief compact par défaut : enveloppe MCP complète ≤ 6 000 octets et ≤ 1 500
  tokens cl100k_base ; sélection lexicale déterministe, validité/portée filtrées,
  références expansibles et mode `detailed` explicite. Les tags `sensitive` sont
  exclus ; ce filtrage n'est pas un détecteur universel de secrets.
- Compteur exact fourni par l'extra `[brief]` (tiktoken 0.12.0) et une table locale
  explicitement configurée, SHA-256 vérifié. Aucun téléchargement implicite ;
  dépendance/table absente = erreur bornée, sans retour implicite au mode détaillé.
- Registre canonique IDs/alias livré **inactif** : aucune variable
  `MEMORY_V4_PROJECT_REGISTRY` en production. Son activation attend un parcours
  de création de projet fluide et un GO distinct ; aucun historique réécrit.
- Défauts inchangés : C4 `scoped_literal` / `lexical_guard_k=3`, JSONL,
  `device=auto` → MPS sur le Mac qualifié, précision native, batch32, longueur512.
  Aucune réindexation par changement volontaire de profil ni bascule CPU.

Le brief réduit le contexte transmis ; aucune preuve nouvelle de supériorité
benchmark ou de classement n'est revendiquée. Les preuves LongMemEval-S/BEAM et
leurs limites restent celles publiées dans le dépôt. Pas de campagne LLM ici.

Qualification requise : suites v3/v4, 20 TCP, 400 mesures FR/EN exactes sur
JSONL/SQLite × serveur/relais, wheel/sdist installés hors dépôt, drill sur copies
récentes du magasin avec baseline4.0.3, réouverture sans réencodage, doctor privé,
relais installés (brief exact, panne/statut local/reconnexion sans rejeu).
La garde reste fermée tant qu'une preuve manque. Voir
`v4/docs/QUALIFY_4_0_4.md` et `releases/4.0.4/QUALIFICATION.md`.
