# 4.1.1 — en préparation (branche `feature/4.1.1`, 2026-11-24)

État : **non publiée, non déployée, non qualifiée**. Aucun GO de publication ni de bascule. Cette note
décrit ce que contient la branche ; elle ne revendique aucun gain mesuré. Elle sera complétée avant la
publication.

- **Cellules de plateforme retenues.** macOS arm64 avec CPython 3.11, 3.12 ou 3.13, et Ubuntu 24.04 arm64
  avec CPython 3.11. Toute autre cellule est refusée. Le profil sémantique reste limité à macOS arm64
  CPython 3.11.
- **Verrous lexicaux figés par cellule.** Chaque cellule embarque son catalogue, son fichier de contraintes
  et un manifeste d'artefacts figé (résolution du 2026-11-24) : pour chacun des 36 paquets, les roues
  admises avec leur nom de fichier, leur URL `https://files.pythonhosted.org/`, leur SHA-256 et leur
  taille. Aucune sdist. Les empreintes de ces fichiers sont ancrées dans le code.
- **SQLite.** Deux routes vers une SQLite conforme, avec relecture par l'interpréteur de l'environnement
  et refus explicite sinon.
- **Amorce.** `scripts/memory_os_bootstrap.py` : un seul script, bibliothèque standard seule, aperçu sans
  écriture, environnement durable.
- **Service.** Une interface de service, deux implémentations : `launchd` (macOS) et `systemd --user`
  (Linux).
- **Clients sous Linux.** Chemins établis pour huit clients ; VS Code, Windsurf et Claude Desktop ne sont
  pas pris en charge sous Linux dans cette version (aucun chemin deviné).

Contrat : `CONTRAT_4_1_1` (rév. 5).
